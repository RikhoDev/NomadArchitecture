# NomadArchitecture Docs

> **Architecture as heritage — a living map of worldview, structure, and lineage.**

Welcome. This is the **campfire** for the documentation.

NomadArchitecture is built on three pillars:

- **Simplicity** — small core, clear contracts, honest structure
- **Intent** — folders scream their purpose, features tell their stories
- **Transmission** — knowledge survives rotation, culture outlasts people

This documentation is ordered by **cognitive readiness**, not by folder depth.
