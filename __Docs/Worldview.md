# Worldview (Doorway)

> **NomadArchitecture is a cultural operating system expressed through software architecture.**

This page orients you before you read the full Worldview. Think of it as the threshold — it tells you what you're about to walk into and why.

---

## The Core Claim

Code rots. People leave. Documentation goes stale. NomadArchitecture answers all three by encoding **intent, evidence, and continuity** directly into the shape of the codebase — so the system teaches itself to its next caretaker.

---

## Six Principles (Summary)

| Principle | One-line | Evidence |
|-----------|----------|----------|
| **Humans at the center** | AI scaffolds; humans decide and leave scars | Trails, chronicles, mirages — all human-authored |
| **Rotation of roles** | No gatekeepers; continuity through rituals | The Shaman rotates; the fire does not |
| **No dumping grounds** | Every file signals its intent | Placement is narrative; orphans get re-homed |
| **Docs as parallel architecture** | Documentation mirrors the cultural logic of the code | `__Docs/` is a pillar, not an afterthought |
| **Trails as proof of life** | Features carry their story — why, how, what happened | README + Map + Traces per feature |
| **The Shaman principle** | Keep the fire alive, interpret meaning, transmit continuity | The role is fleeting, rotating, never owns |

---

## The Five Pillars

| Pillar | What It Holds |
|--------|---------------|
| **Host** | Purpose and delivery skins — replaceable surfaces, never the soul |
| **Features** | Capabilities — what the system can do, portable and auditable |
| **Foundations** | Mechanisms — how the system does it, hardened enablers |
| **Core** | Living commons — shared language, contracts, emergent memory |
| **__Docs** | Story trailhead — teaching, transmission, worldview |
