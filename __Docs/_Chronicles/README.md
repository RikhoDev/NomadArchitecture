## The Underscore Grammar

- `__Name__` → **Pillars**. Canonical, foundational, binding.  
- `_Name_` → **Liminal**. Special, non‑canon, experimental.  
- `Name` → **Emergent**. Named by convoys as they walk the terrain.  

_Chronicles is wrapped in underscores to signal its liminal status: inside the camp, but apart from the hearth.

## Chaptering Convention

Chronicles are written as **chapters**, each in its own file:

- Files are numbered for order: `01_FirstShaman.md`, `02_FirstConvoy.md`, etc.  
- Inside each file, use Roman numerals for chapter titles:  
  - *Chapter I — The First Shaman*  
  - *Chapter II — The First Convoy*  
- The README acts as the **table of contents**, linking to each chapter.
