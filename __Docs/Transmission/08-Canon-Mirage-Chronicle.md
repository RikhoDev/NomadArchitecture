# Layer 08 — Canon vs Mirage vs Chronicle (The Epistemic Backbone)

Not all knowledge is equal.  
Some is proven. Some is speculative. Some is historical.

NomadArchitecture doesn't just organize folders — it organizes **knowledge itself**.

This is the architecture's **epistemic backbone** — how truth emerges and knowledge evolves:

**Canon** — what is true (proven, tested, standing)

- Worldview, Five Pillars, Ports & Connectors
- What we stand behind
- What guides decisions

**Mirages** — what is possible (speculative, unproven, exploratory)  

- Marked `status: non-canon`
- Might be wrong
- Might become canon

**Chronicles** — what is historical (decisions, reasoning, lineage)

- Why things changed
- What was tried and failed
- How canon emerged

**How truth emerges:**

1. Start as Mirage (speculation)
2. Test in practice (proof)
3. Document reasoning (Chronicle)
4. Promote to Canon (truth)

**This is how scientific communities operate.**  
**This is how oral traditions operate.**  
**This is how NomadArchitecture operates.**

**Why this matters:**  
It keeps speculation from masquerading as doctrine.  
It lets experiments happen without contaminating stable knowledge.  
It preserves the path from possibility to truth.

**Read:**

- [_Mirages/](../_Mirages/) — speculative seeds (approach with curiosity, not trust)
- [_Chronicles/](../_Chronicles/) — evolution trail (why things changed)

**When you'll need it:**  
When proposing something new — you'll mark it as mirage first, prove it in practice, then promote to canon.
