# _Trails/

How documents came to be: the conversations, decisions and corrections behind
them, kept verbatim. Trails are not canon. Each one names its document in a
`trail_of:` header, and the
[Trails rule](../README.md#trails-hold-the-conversation) says how they are
named and dated.

To see a document's Trails, run
`pwsh Hosts/DocReader/reader.ps1 trail <path>`.
