# Contributor guidance

This file adds no rules; it points to the canon.

1. Read [Worldview.md](Worldview.md) in full. For a guided start, run
   `pwsh Hosts/DocReader/reader.ps1`.
2. Read [__Docs__/README.md](__Docs__/README.md): what is canon, what each
   kind of document is, and how canon grows.
3. Before placing, moving or promoting anything, apply
   [Architecture](__Docs__/Architecture.md#placement).
4. Before stating a conclusion or acting on one, apply
   [Evidence and Authority](__Docs__/Evidence-And-Authority.md).
5. Before committing, run `pwsh Scripts/Test-Repository.ps1`
   ([Scripts](Scripts/README.md)).

When you draft with an AI assistant, keep the conversation in the document's
Trail, not in the document
([Trails hold the conversation](__Docs__/README.md#trails-hold-the-conversation)).

Replaces nothing. AI assistants had no entry point to this repository's
rules; NGE's `AGENTS.md` shows the value of one.
